# BrewLite – Frontend

Giao diện Next.js (React, TypeScript, TailwindCSS, Zustand) của BrewLite. Hướng dẫn chạy và biến môi trường nằm ở [README gốc](../README.md).

Lệnh thường dùng (chạy trong thư mục `frontend`):

```bash
npm ci
npm run dev      # http://localhost:3000, cần backend ở NEXT_PUBLIC_API_URL
npm run build
```
