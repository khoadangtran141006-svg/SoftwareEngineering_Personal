## Cách chụp (Windows)

- Ảnh tĩnh: `Win + Shift + S`, chọn vùng, dán vào Paint rồi lưu `.png`.
- Ảnh động: dùng một công cụ ghi màn hình thành GIF (ví dụ ScreenToGif), quay luồng Menu → Giỏ → Thanh toán → Xác nhận.

## Trước khi đưa lên GitHub

- Dùng tài khoản demo; **che email, tên và mật khẩu thật**, và không để lộ nội dung `.env`.
- Ảnh nên nhỏ gọn (dưới khoảng 500 KB mỗi ảnh tĩnh).
- Sau khi thêm ảnh, mở `README.md`, tìm khối chú thích `<!-- Ảnh minh họa ... -->`, bỏ dấu `<!--` và `-->` để các ảnh hiển thị, và xóa những dòng ảnh bạn không có.
